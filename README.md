This orphan branch holds project understanding for the served repo. Majordomo operates as a control plane for evolving software repositories, managing durable configuration, caching, and job execution across git hosts. This branch preserves that context without merging into the default branch. Context updates are managed via PRs targeting this branch.
## Story vs Typology evidence
Root markdown files (`mission.md`, `architecture.md`, etc.) constitute the teaching story, providing a refined narrative of the product's mission and architecture.
`evidence/typology/` contains Typology seed evidence (such as `architecture_brief.md`) used to propose digests. These briefs serve as raw input and are distinct from the confirmed `.typology/` catalog and the primary teaching story.
