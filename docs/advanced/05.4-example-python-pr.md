## 🔍 Scenario

A PR changes 20 Python files across auth, api, and models.

## ⚙️ Step 1: Staging and Routing

`scripts/git-diff-prep.py` detects changed files and routes them to `pr-review-code` (the skill that runs code quality review) using default routing.

## ⚙️ Step 2: Dependency Clustering

`scripts/dep_clusters.py` identifies import-connected groups.

Example clusters:

- auth cluster: `handler.py`, `utils.py`, `schemas.py`
- api cluster: `main.py`, `routes.py`
- model singleton: `user.py`

## ⚙️ Step 3: Batch Planning

With a batch size of 15, the script packs clustered files to preserve proximity for related files.

The script writes:

- `pr-review-code` batch manifests
- synthesis manifests (inputs for whole-PR summary and technical review agents)
- `blast-radius` manifest (reverse coupling analysis) if reverse dependencies exist
- one `batch-plan.json` (the orchestration plan dispatch reads to determine wave order)

## ⚙️ Step 4: Dispatch

Dispatch runs file-review and synthesis batches in two parallel waves. Wave 1 runs synthesis skills (`pr-review-summary`, `pr-review-technical`, `pr-review-blast-radius`) alongside the first code batch. Wave 2 runs remaining `pr-review-code` batches. Each wave writes per-file reports to the output directory.

## ⚙️ Step 5: Reverse Dependency Context

If unchanged files import changed files, dispatch includes reverse dependency metadata for synthesis skills.

Example:

- `tests/test_auth.py` imports the changed auth handler
- `src/webhooks/webhook.py` imports the changed auth handler

That context helps `blast-radius` and `summary` classify impact.

## ⚙️ Step 6: Scoring Loops

Summary runs up to 5 iterations (configurable via `SUMMARY_MAX_ITERATIONS`); pass threshold is 15/23. Technical review runs up to 3 iterations (`TECH_MAX_ITERATIONS`); pass threshold is 11/14. The best result is kept when the cap is reached regardless of score.

## 📦 Final Artifacts

- Per-file `<slug>.md` reports (one per reviewable file, in `<output>/pr-review-code/`)
- `findings.md` and `index.md` per skill (aggregated by finalize)
- `summary.md` and `tech-review.md` (synthesis outputs)
- `summary.html` and `tech-review.html` (converted by `md-to-html.py`)
- `findings.xml` (JUnit artifact from `review-to-junit.py`)
